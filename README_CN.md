## 🚀 3分钟快速开始

```bash
# 1. 创建仓库（必须命名为 username.github.io）
# GitHub网页操作

# 2. 克隆仓库
git clone https://github.com/username/username.github.io.git
cd username.github.io

# 3. 复制所有文件到此目录，然后：
git add .
git commit -m "Initial commit: Add website"
git push origin main

# 4. 打开浏览器访问
# https://username.github.io
```

**Done!** 你的网站现已上线！🎉

## ✏️ 3步自定义

### 1️⃣ 修改公司信息（必做）

编辑 `index.html`，查找并替换：

```html
TechVision              → 你的公司名称
驱动未来的技术力量      → 你的主标题
服务中国企业...        → 你的副标题
+86 10-1234-5678      → 你的电话
info@techvision.com   → 你的邮箱
```

### 2️⃣ 修改颜色（可选）

在 `index.html` 中找到 `:root` 部分：

```css
:root {
    --accent-blue: #00d4ff;    /* 改成你的蓝色 */
    --accent-purple: #7c3aed;  /* 改成你的紫色 */
}
```

更多主题选择见 `QUICK_REFERENCE.md`

### 3️⃣ 修改内容（可选）

按照 `QUICK_REFERENCE.md` 修改：
- 功能和服务描述
- 统计数据
- 客户评价
- 导航菜单

**详细说明见 `QUICK_REFERENCE.md`**

## 🌐 部署方式

### 方式1: 个人页面（推荐）
- 仓库名: `username.github.io`
- 网址: `https://username.github.io`
- 最简单的方式

### 方式2: 项目页面
- 仓库可以是任何名称
- 在仓库设置中启用 Pages
- 网址: `https://username.github.io/reponame`

### 方式3: 自定义域名
1. 在GitHub中配置自定义域名
2. 在域名注册商配置DNS
3. 网址: `https://yourdomain.com`

详见 `DEPLOYMENT_GUIDE.md`
